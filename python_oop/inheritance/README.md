# Python - Herencia

Este directorio contiene ejercicios sobre programación orientada a objetos en Python, con énfasis en la herencia y la reutilización de código.

## Archivos

- `base_geometry.py`: Define la clase `BaseGeometry`, que incluye el método `area()` y el método `integer_validator()` para validar valores enteros positivos.

## Conceptos trabajados

- Clases y objetos.
- Herencia.
- Métodos.
- Manejo de excepciones.
- Validación de tipos y valores.
