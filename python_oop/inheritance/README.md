# Python - Herencia

Este directorio contiene ejercicios sobre programación orientada a objetos en Python, con énfasis en la herencia y la reutilización de código.

## Archivos

- `base_geometry.py`: Define la clase `BaseGeometry`, incluyendo el método `area()` y el método `integer_validator()` para validar valores enteros positivos.
- `1-rectangle.py`: Define la clase `Rectangle`, que hereda de `BaseGeometry` y utiliza su método de validación para establecer el ancho y la altura del rectángulo como atributos privados.

## Conceptos trabajados

- Clases y objetos.
- Herencia.
- Reutilización de código.
- Métodos y constructores.
- Encapsulamiento y atributos privados.
- Manejo de excepciones.
- Validación de tipos y valores.
